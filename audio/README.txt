Put narration recordings here, one MP3 per page per language:

  audio/book1/en/page-1.mp3 ... page-8.mp3
  audio/book1/es/page-1.mp3 ... page-8.mp3
  (page-0.mp3 is optional and reads the back-cover summary on the cover screen)

Then set narration: { en: true, es: true } for that book in books.js.
See README.md for recording tips.
